Module 5: Interactive Streamlit Dashboard
8-screen web application. No authentication required for MVP. All screens load from SQLite. Deployed locally via `streamlit run app.py`. All charts are
Plotly interactive; all tables are sortable.
Sprint: Sprint 4 (Days 22–28)

Module 6: Valuation & Market Data Module
Uses market_cap.xlsx to compute and display valuation metrics. Provides historical P/E, P/B, EV/EBITDA trends. Flags companies trading above
historical average multiples (potentially overvalued).
Sprint: Sprint 4 (Days 22–28)
